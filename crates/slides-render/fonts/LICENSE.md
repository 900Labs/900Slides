# Bundled fonts

These three open-licensed fonts are bundled so decks render identically
across platforms without depending on system-installed fonts.

- **Inter-Regular.ttf** — Inter, SIL Open Font License 1.1
  Source: https://fonts.google.com/specimen/Inter
- **SourceSerif4-Regular.ttf** — Source Serif 4, SIL Open Font License 1.1
  Source: https://fonts.google.com/specimen/Source+Serif+4
- **JetBrainsMono-Regular.ttf** — JetBrains Mono, SIL Open Font License 1.1
  Source: https://www.jetbrains.com/lp/mono/
