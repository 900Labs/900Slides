# English (en-US) word list

Source: Webster's Second International Dictionary word list, as distributed
in the BSD `words` file (`/usr/share/dict/words`). This word list is in the
public domain.

This file was filtered to lowercase ASCII words (plus apostrophes for
contractions) of length 2-18, de-duplicated and sorted, with common English
contractions added. It is bundled so spell-check works fully offline with no
network dependency.

Approximately 233,000 entries.
